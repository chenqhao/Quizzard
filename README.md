# Quizzard

A quiz web app allowing student to create their own quizzes, tracks progress and generate problems via the Gemini API

## Techstack

- Next.js
- React 
- Tailwind CSS
- Supabase
- Gemini api 
- Node.js 

## Features

### AI Quiz Generation
- AI generates quiz questions for users based on course notes
- Generated questions can be adjusted by difficulty, problem type and number of problems

### AI Grading

- Written questions can be evaluated and graded via Gemini assignning a score and providing detailed feedback 

### Progress Tracker

- Heatmap tracking number of questions completed per day
- Tracks questions done per subject 
- Overall stats tracking Accuracy score, study time, streaks, questions answered and quizzes taken

### Leaderboard and friends

- Friends can be added via unique user IDs
- Friends can share problem sets with each other 
- Competitive leaderboards tracking questions completed, accuracy, and total study time among friends

### Course organization

- Courses are structured through a folder system by Subject → Course → Unit

### Global search 

- Spotlight search system
- Ctrt/Command-k hotkey
